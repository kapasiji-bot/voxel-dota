# Voxel DOTA — Architecture

A single offline HTML file (`voxel-dota.html`) built from small ES5/ES2017 script modules in `src/`. Every module runs in **one shared scope**: `build/build.js` concatenates them in MANIFEST order inside a single IIFE. There are no imports. Anything declared at a module's top level is visible to every later module, and to earlier modules once the game is running.

## Data flow
`frame()` (rAF) → `step(dt)` in fixed substeps of ≤ 0.05 s × timeScale:
modifiers tick → `tickInvis` → AI (creep/tower/hero orders) → `updateCasting` / `updateAttack` → projectiles, timers, effects → waves and gold → `tickVision` (fog grid, every 0.2 s) → `syncModel` (animation) → `renderFog` → particles, HUD, overlay, minimap.
- **Orders:** input or AI calls `issueOrder(h, {type:'move'|'attack'|'amove'|'idle'|'cast', ...})`. Casts go `orderCast` → walk into range → `beginCasting` (cast point) → `executeCast` → `def.onCast(ctx, target)`.
- **Attack cycle** (`combat/attack.js`): `u.atk = {id, target, phase:'windup'|'backswing', t, point, back}`.
  1. Windup lasts `atkPoint / atkSpeedMult`.
  2. At the end of the windup comes the **impact**. A melee attack deals damage here. A ranged attack launches its projectile here and deals damage when it hits.
  3. Backswing follows.

  Windup and backswing are capped at 98% of the attack interval. The attack is cancelled before the attack point if the target dies or becomes invulnerable, leaves range by more than 2, the unit is stunned or taunted, or a new order arrives; a cancel refunds the cooldown. The backswing can be cut by a move order, but never on the impact frame itself. The animation reads only `u.atk`, so the impact keyframe and the damage happen in the same frame.
- **Stats:** `refreshHero`/`refreshUnit` rebuild derived stats from base stats, items (`ITEM_DEFS[id].props`), passive abilities (`passiveProps`) and modifiers (`props`, plus `stackProps × stacks`).
- **Status flags:** each step, `updateStatusFlags(u)` turns modifier `states` into the flags `u.rooted` (movement blocked; also set while stunned), `u.disarmed` (no new attacks, windup cancelled), `u.silenced` (`canCast` refuses) and `u.hexed` (speed capped at 2.8). `stunned` skips AI entirely.
  - Shared defs live in `MODS`: `stun` (star ring over the head), `root`, `silence`, `hex` (model swapped for a voxel frog), `knockup` (airborne stun that lifts the model on a parabola), `frozen` (root + disarm inside an ice block) and `slowed` (snow particles).
  - Attach a status visual with `attachFx(u, key, make)` and remove it with `detachFx(u, key)`.
- **Channelling** (`abilities/channel.js`): an ability with `channel: seconds` starts `h.channel` after `onCast`.
  - Each frame `onChannelTick(ctx, target, dt, ch)` runs; returning `false` breaks the channel.
  - The channel ends through `onChannelEnd(ctx, target, interrupted, ch)` with `reason` set to `done`, `order`, `stun`, `hex`, `silence`, `broken`, `target` or `death`.
  - Any `issueOrder` interrupts it, as do stun, knockup, hex, silence and death. The HUD shows a channel bar and the model holds a channel pose.
- **Heroes and match:** `G.heroes` lists every hero; `G.player` is the human one, always Radiant.
  - `startGame(id, opts)` creates the player's hero, then `setupMatch(id, {enemies 0-5, allies 0-4, diff 0-2})`.
  - Computer heroes are random and never the same hero as the player. Duplicates are only possible across teams, when there are more than 5 bots.
  - Lane splits: Dire 1→mid, 2→mid/top, 3→mid/top/bot. Radiant allies take bot, then top, etc.
  - `updateHeroTimers` (cooldowns, regen, respawn) and passive gold run for **every** hero.
- **Kills** (`combat/kills.js`):
  - Credit goes to the killer hero, or else to the enemy hero who did the most recent damage within 12 s. Every other enemy hero who did damage within 12 s gets an assist.
  - Bounty: 150 + 8 × level, + 50 per victim streak (max 5).
  - XP is split among enemy heroes within 24 (creep XP within 16).
  - Respawn time is `min(60, 5 + 2.4 × level)`.
  - Kill feed (Chinese) includes first blood and streak names.
  - Destroying a building gives every hero on the attacking team its bounty.
- **DOTA aggro rule** (`heroAggro`): when a hero's *attack* damages an enemy hero, enemy towers that have both heroes in range switch to the attacker (`towerAggro` event). Nearby enemy lane creeps also switch, for 2.5 s.
- **Bots** (`ai/bot/`): `loop.js` calls `botUpdate(h, dt)` before `heroAI`. Bots think only every `diff.tick` seconds: 0.30 / 0.20 / 0.12 s, so 3–8 Hz.
  - Bots issue the **same orders as the player** (`issueOrder`, `orderCast`, `useItem`, `buyItem`, `learnSkill`). Bot orders end in `stand`, which means no auto-attack, so the bot controls its own last hits.
  - Each tick runs these priorities in order:
    1. level skills (ult at 6/12/18)
    2. shop (`ai/bot/shop.js`): always keep a TP; salve only in base when none held, < level 11, max 6 per game; supports buy observers (level 2+); sentries when the team has ward intel or an enemy can go invisible (one per team); dust; then the role build (`BOT_BUILDS` carry/tank/support, cheap stat components first so gold isn't hoarded). Away from base purchases go to the stash.
    3. keep channelling unless HP is very low
    4. retreat to the fountain and heal, with hysteresis (TP home when safe and far); after healing TP back to the lane (`botTpLane`, saves ≥ 38 distance, after 1:00)
    5. defend base structures under siege, or TP to an own tower that is being pushed by heroes (level 6+, `defendTarget`)
    6. ward (`botWards`, when calm): sentry at intel spots / lane vs invisible heroes, observers at the nearest unwarded spot of `WARD_SPOTS_RAD` (mirrored for Dire), attack visible enemy wards within 16
    7. fight a hero chosen by `pickFightTarget` (`ai/bot/fight.js`: burst incl. spells off cooldown and mana, disable time, ult ready, ally/enemy count incl. memory ghosts, own/enemy tower, low-mana penalty), never diving under towers except on 困难 when the target is killable; cast spells first, use blink/BKB
    8. lane: stand behind the own creep front, step out of enemy tower range when it isn't tanked, last-hit/deny using predicted creep HP, harass, push structures when no enemy heroes are near or after 8 min
  - Spell use comes from ability metadata: target type, `values.dmg/dps/stun/radius/len`, `ult`, `channel`.
    - Optional hints `ai: { disable, selfAoe, global, finisher: '<value key>', mana, skip, killDmg(h,ab,t), aoe: n, debuffId, hpBelow, engage, escape: 'blink'|'invis'|'orb', nuke, dodge, reflect }` go on an ability (see the header of `ai/bot/abilities.js`).
    - Optional hints `ai: { skills: [...], role: 'carry'|'tank'|'support', aggr }` go on the hero (role defaults from the primary attribute; `aggr` multiplies fight willingness from level 6).
    - `botEscape` uses escape hints while retreating (Puck orb + jaunt, AM blink, BH Shadow Walk, Phase Shift); `botReact` reflects/dodges incoming casts. Invisible bots (level 5+) fight more readily.
    - Fog: bots only see what their team sees; they remember last-seen positions for 3 s, buy 显影之尘 when an enemy hero can turn invisible, and use it when damaged by an unseen hero or when an invisible-capable foe vanishes nearby.
  - Difficulty sets reaction chance, aim error/lead, last-hit accuracy, retreat HP and aggression.
- **Shop rule** (`entities/shop.js`): `atShop(h)` = the hero stands inside its own base (`inBase`). `buyItem(id, h)` checks gold → team stock (`def.stock`, 库存不足) → `def.maxCharges` → puts the item in the inventory when at the shop (stash if the inventory is full), otherwise into `h.stash` (max 6; `buy{stash:true}`). `tickShop` restocks and moves the stash into free inventory slots whenever the hero is in base (`stashDeliver`). Selling (`sell`) only works in base. The shop panel shows a green/red hint (`#shopHint`), the stash row and a badge on the shop button. Bots use the same rules.
- **Wards** (`entities/wards.js`, items `ward_obs` / `ward_sentry`): wards are units of kind `ward` (`isWard`). Observer: vision 16, 6 min, team stock 2 (+1 every 75 s), carry 2. Sentry: true-sight radius 9 (reveals invisible units and wards; no vision of its own beyond 4), 7 min, stock 4 (+1 / 45 s). Both are permanently invisible (`MODS.wardInvis`), so the enemy needs a sentry/dust to see them; 3 HP, only hero attacks hurt them (1 per hit; spells, creeps and towers ignore them). Kill = 50/30 gold (`wardKill`), deny = half (`wardKill{deny:true}`). Placed with the ground-target cursor (preview circle = `active.radius`), walk-to-range via the `useItem` order. Placing a ward inside enemy vision records it in `G.wardIntel[enemy]` (bots then buy sentries).
- **Town Portal** (`items/tp.js`): `tp` item (90 gold, stacks to 3). A 3 s pseudo-ability channel (`startChannel(h, {def: TP_CH, lvl:1}, dest)`, `keepOn: ['silence','root']` so only stun/hex/death/orders interrupt). `tpDest(h, pt)` = own building (tower, barracks, fountain; not the ancient) nearest the clicked ground/minimap point, default fountain (press the key twice). Swirl effects at origin and destination (`G.tps`), drawn only where the viewer's team has vision; pulsing rings on the minimap. Events `tpStart`, `tpCancel`, `tpArrive{building}`. The scroll is consumed on use; hero cooldown 60 s (`def.heroCd` keeps the cooldown in `h.icd` so a newly bought scroll is still on cooldown).
- **Item def fields:** `stack` (charges stack in one slot), `consumable` (use spends a charge), `maxCharges`, `heroCd`, `stock {max, every, start}`, `basic` (stat item), `keepInvis`; `active.optional` (point target may be omitted), `active.clamp` (blink clamps instead of walking), `active.radius` (placement preview). A point item used out of range issues the `useItem {slot, x, z, range}` order (walk, then use).
- **Fog of war** (`vision/fog.js`): `VIS[team]` is an 80×80 cell grid (1 cell = 1 tile = 2 world units), recomputed every `FOG.period` = 0.2 s, or at once when `FOG.dirty` is set (addUnit, teleport, respawn, `addVisionAt`).
  - Sources: heroes 22 (night 14), creeps 14/9, towers 24/16, fountain 26, other buildings 18/14; `u.visionBonus` adds to a unit's radius. `addVisionAt(team, x, z, r, dur)` adds temporary vision (Puck's orb, Zeus' wrath).
  - Line of sight: per-radius templates list, for each target cell, the cells whose *centre area* the line from the source passes through. Trees and cliffs (`sightBlock`) block; the blocking cell itself is visible. Static building vision is cached per day/night. Measured cost ≈ 0.03 ms per update (60 live units, headless).
  - `canSee(team, u)`: own team or building → true; dead → false; `hidden` state → false; a `reveal` modifier from that team (Track) → true; `trueSight` (Dust) ignores invisibility; otherwise `isInvisible(u)` → false; then `FOG.off` or the grid.
  - Day/night: 5 min each (`isNight()` = `G.time % 600 ≥ 300`); lighting and fog colour lerp in `render/fogrender.js`; the HUD timer shows 昼/夜.
  - Who uses it: attack windups cancel on unseen targets, `findEnemy` / creep / tower acquisition skip them, `validSpellTarget` refuses unseen enemies, bots perceive only `canSee` enemies (plus 3 s memory ghosts, `knownFoe`). Buildings are always visible (last-seen HP shown). The Tab scoreboard shows everything.
  - `FOG.explored[team]` ORs every grid ever seen. Wards: observer radius 16 (no creep dedupe); invisible units are visible to a team with a live sentry within 9 (`sentrySees`). Towers have no true sight (by design).
  - Render: fogged fragments are darkened, 55 % desaturated and tinted cool blue; never-explored cells are darker still (texture G channel). Minimap: fog overlay alpha 185 (explored) / 228 (never seen). A DataTexture (`FOW_TEX`) sampled in the patched `fog_*` shader chunks darkens unseen terrain/models; enemy models, health bars and minimap icons are hidden when `!canSee(RAD, u)`; own invisible units use ghost (38 % opacity) materials.
- **Invisibility** (`vision/invis.js`): a modifier with `invis: true` (fade via `data.fade` seconds). `breakOn: 'remove'` (Shadow Walk; optional `onBreak(u, m, why, target)`) or `'pause'` with `refade(u, m)` (Riki: revealed for N s, then fades again). Attacks (`attackImpact`), casts (unless the ability/item has `keepInvis`, or the mod `keepOnCast`) and item use break it. An ability with `passiveMod` keeps that modifier applied while learned.
  - Detection: `MODS.dusted` (true sight + 20 % slow, item 显影之尘), a `reveal: true` modifier (Track). Towers have no true sight.
- **New states and props:** states `invulnerable` (no damage, enemy debuffs refused, untargetable), `hidden` (removed from enemy vision; Phase Shift, Tricks of the Trade), `reflect` (Counterspell). Props `magicRes` (multiplicative; heroes have 25 % base), `miss` (this unit's attacks miss), `evasion` (attacks against it miss) → `u.missChance`, `u.evasion`; misses emit `attackMiss` and float 未命中.
- **Recast / reflect:** an ability with `recast(h, ab)` → true can be pressed again for free (castPoint 0) and runs `onRecast(ctx)` (Puck's jaunt; emits `cast{ability:'orb:recast'}`). `clampRange: true` point spells cast at max range instead of walking (Anti-Mage blink). A unit with the `reflect` state blocks an enemy unit-target spell and re-casts its `onCast` from itself onto the caster (non-channel spells; `spellReflect`).
- **Auras** (`abilities/aura.js`): an ability with `aura: {radius, mod, props(ctx, unit), heroesOnly}`. Every 0.25 s the aura re-applies `mod` with a 0.6 s duration to allies in radius.
- **Hero hooks** on learned abilities:
  - `onAttacked(ctx, attacker)`
  - `onAttackLand(ctx, target, dealt)`, used for cleave; extra damage dealt this way never carries the `attackId`
  - `onAbilityCast(ctx, ab)`, used by Static Field and Fiery Soul
  - `passiveProps(ctx)`
  - `modifyAttack(ctx, target, info{dmg, crit, attackId})` before attack damage (Jinada crit, Riki backstab)
  - modifier `onDeath(u, m, killer)` (Track bounty)
- **Stat props:** `armor dmg dmgPct (heroes, % of base damage) as ms msPct str agi int hpRegen manaRegen dmgTakenPct`.
- **All HP loss goes through `dealDamage`**, which handles armor, magic immunity, `dmgTakenPct`, god mode, and the death, gold and XP events.

## Summons, illusions, unit control, trees (B4)
- **Owned units** (`isOwned(u)` = `isSummon || isIllusion`; wards also carry `owner` but are not owned units): `u.owner` is the hero. `ownerOf(u)` resolves damage/kill credit, so bounty, last hits and kill credit go to the hero. Owned units take orders through `heroAI` exactly like heroes (`order`/`path`), tick their ability cooldowns + regen (`updateUnitTimers`) and run ability hooks (`onAttackLand`, `modifyAttack`, ...) from `u.abilities`.
- **Summon types**: `registerSummon({id, name, hp, armor, dmg, bat, range, speed, gold, xp, vision, push?, quad?, dieWithOwner?, abilities?, model(team), portrait})` (in the hero file). Spawn with `AB.summon(owner, type, x, z, {lvl, hp, dmg, armor, dur, ...})`. Events: `summon {stype}`, `summonDeath {stype, expired}`.
- **Illusions**: `AB.illusion(h, {x, z, dur, out, inc})`. They take `inc`× damage and deal `out`× damage (applied first in `dealDamage`), cannot cast, do not trigger item passives, skip abilities marked `noIllusion`, and are not in `G.heroes`. Enemies see a normal hero; the own team sees a blue tint (`setTint`). Events: `illusion`, `illusionDeath`.
- **Control** (`ui/control.js`): `CTL.sel` (hero first), `ctlActive()` drives the HUD, and QWER go to the active unit if it can cast (bear), otherwise to the hero. Right-click and A/S/H apply to the whole selection with formation offsets.
- **Trees**: `destroyTree(k)` / `sproutTree(x, z, dur)` → `setTreeCell` updates `walk`, `sightBlock`, `TREES.gen` (part of the static vision cache key), `TREES.changes` (render + minimap), `FOG.dirty`. Natural trees regrow after `TREE_REGROW` s.
- **Forms**: `AB.formMod({...key, def, scale, props, height})` returns a modifier def that swaps the model while it lasts (Lycan wolf form, Lone Druid True Form).
- **Recipes**: item `parts: [ids]` — `buyItem` consumes owned parts (inventory or stash) and charges `itemPrice(h, id)` (cost − parts). `uniqueGroup` (boots) prevents stacking. Item hooks: `onAttackLand` (cleave), `tick` every 0.5 s (auras), `block`.
- **New ability fields**: `check(h, ab, target) → error|null` (precondition), `ai.summon`, `ai.trees`, `ai.tp`, `ai.skip`, `ai.escape: 'aoe'`.

## Channelers, toggles, walls (B5)
- **Toggle abilities** (`abilities/toggle.js`): `toggle: true` on an ability. Casting flips it (`toggleAbility(h, ab, on)`): switching on pays `mana`, switching off starts the cooldown. While on, `tickToggles` drains `values.drain` mana per second and calls `onToggleTick(ctx, dt)`; it switches off on death or when mana runs out. `onToggle(ctx, on)` optional. HUD shows `.toggled`. Event `toggle{unit,ability,on}`. Cast hooks (`onAbilityCast`) still fire.
- **Displacement / bounces** (`abilities/displace.js`): `AB.pull(u, x, z, dist)` (walk-checked, cancels the attack), `AB.shove(u, dx, dz)`, `AB.bounce({src, from, first, jumps, radius, speed, color, size, delay, rebounce, unique, filter, pick, onHit, ability})` — a visible projectile that hops between targets; `rebounce: true` allows A→B→A (never the current target twice in a row), `unique` hits each unit once. Event `bounce{unit,target,n,ability}`. `fireProjectile` takes `o.from` (unit or point).
- **Terrain walls** (`map/walls.js`, `render/walls.js`): `wallLine(x, z, dir, len)` → cells (skips cliffs/base/buildings), `addWall(cells, dur, by, side)` raises `blockCount` → `walk`, shoves units standing on it sideways, resets every path; expiry (`tickWalls`) restores the cells. Walls don't block vision. Events `wallUp`, `wallDown`.

## Bot teamwork (B10)
- **Coordinator** (`ai/bot/team.js`): `teamTick(team)` once per second (from any bot's think) keeps `G.teamAI[team] = {mode, t0, members (all team bots; dead ones join on respawn), target, rally, phase, …}`. Priority: **defend** (own tier ≥ 2 / barracks / ancient hit with ≥ 2 known enemy heroes near) → **roshan** (committed: no time-out; aborts to retreat only when known enemies at the pit out-power the members ×1.2 or < 2 members remain; Roshan dead → follow-up push `why:'aegis'`) → **retreat** (8–12 s regroup at the nearest own tower; low-HP members go home) → start **roshan** (Roshan up, ≥ 3 bots of level ≥ 9, advantage ≥ 2 or game time ≥ `diff.rosh`, enemies ≤ 2 alive or none known near the pit) → **push** → **free**.
- **Push** (`ai/bot/teampush.js`): starts at `diff.group` (普通 15:00), at 60 % of it when ahead, or at once after a won fight (enemies alive ≤ ours − 2). Target = attackable enemy structure closest to the group (−22 where our creeps already are, −12 barracks, −60 the ancient, +12 per known defender). Rally 19 behind it on its lane; `gather` until ≥ 3 members are there (or 25 s), then `siege` (members attack creeps near them, else the structure; fighting under that tower is allowed with ≥ 2 allies — `teamDive`). Structure down → chain to the next one while ≥ 3 members and average HP > 50 %. Retreat when ≤ 1 member, average HP < 30 % or (not after a won fight) known defenders out-power the team ×1.6; time-out 150 s.
- **Per bot** (`ai/bot/teamexec.js`, from `botJungle` after loot, before camp farming): plan execution (TP to the rally / defence when > 50–55 away, `BOT_TP_GAP.group` 120 s); **pick-offs**: from 5:00, a visible enemy hero with no other known enemy within 20 and not under its tower → the 2–3 nearest free bots whose power beats it ×1.4 get `b.gank` for 12 s (chance `diff.gank` per check).
- **Loot**: Aegis → the team's carry near the pit (else highest level); Cheese → a carry without Aegis, else a support. **Difficulty**: `DIFFS[i].group / rosh / gank` = 简单 21:00 / 22:00 / 0.25, 普通 15:00 / 15:00 / 0.6, 困难 12:00 / 13:00 / 0.9.
- **Economy tune**: `XP_MULT` 1.4 → 2.4 and hero-kill XP 60 + 28·lvl → 100 + 40·lvl, so bots are ~lv 13 at 20 min and ~18 at 35 min.

## LAN multiplayer (B11)
- **Transport**: WebRTC DataChannel, `iceServers: []` (LAN only, no signalling server). The host makes one **邀请码** per joining player (`rtcOffer`), the joiner pastes it and gets an **应答码** (`rtcJoin`), the host pastes that back (`rtcAccept`). Codes wait for ICE gathering to finish, then `net/sdp.js` strips the SDP to ufrag / pwd / fingerprint / setup / candidates (mDNS `.local` UUIDs packed as 16 bytes), deflate-raw (CompressionStream) + base64url → `VD1` + `O|A` + `z|p` + data, ≈ 175 chars; the receiver rebuilds a minimal data-channel SDP. Failures (no candidates, ICE failed, timeouts, bad code, version mismatch, room full, host gone) are shown in Chinese. Star topology: up to 9 clients connect to the host; the host relays.
- **Netcode: host-relayed deterministic lockstep** (not snapshots — sim state is full of closures (`delay` timers, modifier callbacks, projectile `onHit`, effect `update`) and three.js objects, so it cannot be serialized; lockstep only needs determinism, costs a few bytes per tick, and makes rejoin-by-replay possible). Fixed tick `NSTEP = 1/30` s. Each tick the host broadcasts `{t:'f', n, c:[cmds]}` and executes it; clients execute frames in order (catching up when behind) and ack every 3 ticks; the host stays ≤ `NAHEAD` (15) ticks ahead of the slowest connected peer. Render-time interpolation of unit x/z (`lsInterp` / `lsRestore`; real values always restored before a tick).
- **Determinism**: in a LAN match only, `Math.random` is replaced (`rngInstall`): inside `simRun` (sim) it is a seeded sfc32 (`rngSeed(spec.seed)`); inside `visScope` (particles, floats, sounds, announcer, model animation) it is the native RNG and must never touch sim state. Visual-only randomness in sim files uses `vrand` / `vrnd`. **Rule for new code: never let fog / visibility / camera / local player decide whether a sim-side `Math.random()` is called.** Every 30 ticks clients send `stateHash()` (FNV of units, RNG state, tick); a mismatch shows the Chinese desync warning (`NET.desync`). Debug: `NET.trace`, `NET.rngLog`, `NET.dumpAll`.
- **Commands** (`net/wrap.js`, `net/cmds.js`): UI calls (`issueOrder`, `useItem`, `buyItem`, `sellItem`, `learnSkill`, `toggleAutocast`, `courierOrder`) are rebound (one IIFE scope) to send `{k, …}` commands (units as `{$u:id}`, drops as `{$d:id}`); the host stamps the issuer slot `p`, and `execCmd` runs the original (`NET_ORIG`) only for units the issuer owns (hero, its summons / illusions, its courier). Bots and sim code call the originals directly (`RNG.sim > 0`).
- **Lobby** (`net/lobby.js`): host-authoritative; 10 slots (0–4 天辉, 5–9 夜魇), names, unique hero picks, ready, host-only bots (difficulty per bot, 填充 / 清空电脑), kick, start when every human is ready and has a hero. `netBuildSpec` → `start` → `netBegin` (seed, heroes in slot order, lanes, couriers).
- **In game**: chat (Enter team, Shift+Enter all, host filters + relays), pause only by the host (P), ping in the net HUD, **drop** → host issues a `drop` command at a tick → the hero becomes a bot (`makeBot`); **rejoin** via the host's 邀请 / 重连 button (new code) → `resume` sends the spec + full command log → the client fast-forwards (`ffRun`, sounds / messages muted) → `human` command hands the hero back. Host leaving / timing out (`NET_DEAD` 15 s) → clients get `#netEnd` (对局无法继续).
- **Tests** (`tests/net.js`, helpers `tests/netlib.js`): several pages in one browser context with `?netfake=1` — real RTCPeerConnections create / accept the codes, but the bytes go over a `BroadcastChannel` (the sandbox Chrome policy `WebRtcIPHandling=default_public_interface_only` yields no ICE candidates). `GameAPI.netNoRender(true)` skips WebGL rendering in multi-page tests. Internet play would need a signalling server + STUN/TURN (not implemented).

## Adding an item
Create `src/items/<id>.js` containing `registerItem({id, order, name, en?, icon, cost, desc, parts?, cat?, props?:{str,agi,int,dmg,armor,as,ms,hp,mana,hpRegen,manaRegen,magicRes,evasion,trueStrike,...}, unique?, consumable?, tick?, modifyAttack?, onAttackLand?, active?:{target:'none'|'unit'|'point', targetTeam?, range?, cd, mana?, onUse(ctx, target)}})`. It shows up in the shop (tab from `itemCat`) automatically; add it to a bot build (`BOT_BUILDS` or hero `ai.build`) and, for actives, a rule in `ai/bot/actives.js`.

## Conventions
- Shared scope means unique top-level names. Prefix hero and item constants (`AXE_*`, `BKB_MOD`).
- Files stay under 300 lines; split one when it grows. Files starting with `_` are never bundled.
- Order dependencies matter only for top-level *execution*, such as registry calls running after `state.js`. Function references resolve at runtime.
- UI text is Simplified Chinese. Code and comments are English.
- Units: 1 tile = 2 world units, and ranges are in world units. Time is in seconds of game time (`G.time`). Use `delay(t, fn)` rather than `setTimeout`.
- Gameplay logic never reads the render state. Rendering only reads the sim state.
